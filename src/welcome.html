🚀 GitHub & API Configuration Guide

Follow these quick links to configure settings inside the extension popup.

1

GitHub Personal Access Token (PAT)

Secure key to upload solutions. Do NOT select any extra checkboxes (only select "repo").

  1. Open the GitHub New Token Page.
  2. Ensure **ONLY** the repo checkbox is selected (required to save files).
  3. Click Generate token at the bottom and copy your key (starts with ghp_).
2

GitHub Repository Path

Your target repository to save solutions.

  1. Create a repository via the New Repository page (Public or Private).
  2. Copy the path formatted as username/repo-name.
  3. Example: If username is alex and repo is dsa, path is: alex/dsa.

🔒 100% Private & Secure

  • No Backend Server: CommitDSA has no database or external servers. We cannot see, store, or intercept your credentials.
  • Local Storage: All keys, repository names, and settings are saved locally and securely in your own browser's storage (chrome.storage.local).
  • Direct Connections: The extension communicates directly with GitHub API endpoints using encrypted HTTPS protocols.
