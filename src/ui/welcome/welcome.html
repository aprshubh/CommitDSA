Interactive: CommitDSA syncs solved problems and displays a manual confirmation overlay inside your browser context for privacy-first control.

100% Private & Secure

  • Local Storage Only: All configurations, GitHub Personal Access Tokens, and solving states are stored directly in your local browser sandbox (chrome.storage.local).
  • Serverless Architecture: CommitDSA runs entirely in the background worker of your browser. We have zero external servers, analytics tracking scripts, or telemetry databases.
  • Encrypted Direct APIs: The extension connects straight from your client machine to the official GitHub API via HTTPS protocols, keeping all data transfers secure.

Quick Start Steps

1

Pin the Extension

Click the Puzzle piece icon in your Chrome toolbar, find CommitDSA, and click the Pin icon to lock it for easy access.

2

Login to Platforms

Make sure you are signed in on leetcode.com and geeksforgeeks.org so the extension can detect your accepted submissions.

3

Start Coding!

Solve challenges! Upon acceptance, a confirmation banner will prompt you to push your solution. View your statistics inside the extension popup.

⚙️

GitHub & API Configuration

Configure these parameters inside the extension popup's settings menu:

1

Generate GitHub Token (PAT)

You need a secure token to allow the extension to write solutions to your repository. Do NOT select any extra checkboxes (only select "repo").

  1. Visit the GitHub New Token Page.
  2. Verify that only the repo checkbox is selected.
  3. Click Generate token at the bottom, and copy the key (it starts with ghp_).
2

Configure Repository Path

Set the path of your target repository in your extension settings.

  1. Create a new repository (Public or Private) via the New Repository Page. Important: Check the box to "Add a README file" to initialize the default branch.
  2. Copy your path formatted as username/repo-name. For example: aprshubh/DSA.
